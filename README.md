# Dragon Animation

Dragon Animation built using HTML, CSS and a bit of JavaScript — a small, responsive animation that demonstrates layered CSS artwork and keyframe motion.

![Dragon Animation Screenshot](Screenshot%202024-08-30%20111324.png)

## Overview

This repository contains a lightweight, single-page animation of a dragon created with semantic HTML, handcrafted CSS, and minimal JavaScript for interactivity. The project is intended as a visual demo and a learning resource for CSS animation techniques, layering, and transforms.

Key highlights:
- Purely front-end: open `index.html` to view the animation.
- Heavily CSS-driven — styles are in `style.css`.
- Clean, easy-to-follow structure for learning and remixing.

## Screenshot

The screenshot above shows the dragon animation as rendered in a desktop browser. For the live experience, open the `index.html` file in any modern browser (Chrome, Firefox, Edge, Safari).

## How to run

1. Clone or download this repository.
2. Open `index.html` in your browser:

   - Double-click the file, or
   - Run a simple local server (recommended for best results):
     - Python 3: `python -m http.server 8000`
     - Then visit `http://localhost:8000` in your browser.

## Files

- `index.html` — the page markup for the animation.
- `style.css` — all styling and animation rules.
- `Screenshot 2024-08-30 111324.png` — preview image used in this README.

## Customization

Want to tweak the animation?
- Open `style.css` and look for the `@keyframes` blocks and transform/transition rules.
- Modify colors, speeds, and transforms to explore different motion effects.
